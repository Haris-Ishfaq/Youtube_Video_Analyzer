About This Project

Final Year Project — Department of Software Engineering, University of Azad Jammu & Kashmir (UAJK)

Project Abstract

YouTube has become one of the largest platforms for user-generated content, where millions of users interact through comments every day. These comments contain valuable insights regarding public opinion, engagement patterns, trends, and potentially harmful behavior such as spam and toxicity. The YouTube Video Analyzer (YT-VA) is an AI-driven web-based application designed to analyze, visualize, and interpret YouTube comments using Deep Learning, Natural Language Processing (NLP), and Transformer-based models.

The system collects comments from YouTube videos using the YouTube Data API and processes them through multiple AI models to perform spam detection, toxic content filtering, bot identification, topic clustering, intent prediction, and trend matching. An interactive visualization dashboard presents the analyzed data in graphical form, enabling content creators, researchers, and marketers to gain meaningful insights.

Problem Statement

Manual analysis of YouTube comments is inefficient, subjective, and unsuitable for large-scale datasets. Content creators and organizations struggle to identify spam, toxic behavior, and bot activity in real time. Existing tools often focus on limited metrics such as likes or basic sentiment, lacking deeper analysis like topic clustering, intent prediction, and trend matching.

Proposed Solution

YT-VA automates the collection and analysis of YouTube comments using Deep Learning, NLP, and Transformer-based models. The system extracts comments via the YouTube Data API, preprocesses text data, and applies multiple AI models. An interactive dashboard presents actionable insights to content creators, moderators, and researchers.

System Modules
01
Visualization Dashboard

Interactive dashboard displaying comment distribution, bot ratio, confidence histograms, topic distribution, intent breakdown, and trend alignment using Plotly charts.

✓ Fully Implemented

02
Toxic & Spam Detection

Trained Keras Deep Learning model (183K+ vocabulary) classifies comments as normal, spam, or toxic with confidence scores and hybrid NLP signal overlay.

✓ Fully Implemented

03
Bot Ratio Detection

ML + pattern matching hybrid model analyzes author name and comment text to estimate bot probability per comment and overall bot ratio in the video.

✓ Fully Implemented

04
Topic Clustering

Groups comments into meaningful topics using BERTopic with SBERT embeddings. Automatically discovers discussion themes without any training.

✓ Fully Implemented

05
Intent Prediction

Zero-shot classification using HuggingFace Transformers to understand user intent: questions, feedback, hate speech, promotions, appreciation, criticism, and more.

✓ Fully Implemented

06
Trend Topic Matching

Matches extracted comment topics with current trending keywords across 11+ categories (Technology, Gaming, Music, Sports, etc.) using semantic similarity.

✓ Fully Implemented

Software Process Methodology

The project follows the Agile Software Development Methodology, allowing iterative development, continuous testing, and regular feedback. Each sprint includes requirement analysis, development, testing, and review phases. This approach enabled the team to implement 6 complete modules within the project timeline.

System Limitations
Depends on YouTube API quota limitations (10,000 units/day default)
Classification accuracy depends on training data quality and may vary by content domain
Primarily focused on English-language comments in current version
Analysis only — not a real-time moderation enforcement system
Maximum 100 top-level comments fetched per analysis due to API limits
Advanced modules (Topic, Intent, Trend) require additional RAM (4GB+ recommended)
